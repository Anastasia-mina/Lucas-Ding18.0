# 钉钉风格酒馆美化 1.18 适配版

署名 Lucas。禁止二改、二传及商用。

插件版本为 1.0.3-st18.1，目标版本为 SillyTavern 1.18.0。本包与原有 1.19 包分开提供。你当前的 1.19 酒馆和原版安装包没有被替换。

## 安装

1. 解压 dingtalk-tavern-1.18.zip。
2. 将整个 dingtalk-tavern-18 文件夹放入你要使用的 1.18 酒馆的 public/scripts/extensions/third-party/ 目录。
3. 刷新酒馆。扩展列表中会显示钉钉桌面聊天美化的 1.18 适配版。
4. 如果界面没有自动启用，展开该扩展，点击启用钉钉美化。

请只启用一份钉钉美化。如果该酒馆里还有 1.19 版，先在管理扩展程序中关闭 1.19 版，再启用本版。只点击恢复原界面不会卸载扩展。

ZIP 包用于本地文件安装，不能直接填入从 Git 仓库安装的地址栏。手机或远程部署需要把文件放入实际运行酒馆的那台设备。

## 功能

- 钉钉风格的侧栏、会话列表、聊天气泡和输入区。
- 手动浅色、深色，跟随系统外观，按本机时间自动切换。
- 默认白天 07:00 开始，夜晚 19:00 开始。可以更改时间。
- 搜索角色与最近消息摘要，置顶会话，查看聊天记录。
- 保留酒馆原生角色管理、API、世界书、生成设置和消息编辑。
- 外观设置中可恢复原界面。
- Lucas 署名及使用限制保留在外观设置、工作台和扩展设置中。
